<Highlight n="04" kicker="Hermes · Messaging & bridge" title="Every server speaks to the rest." body="Hermes carries messages across servers and out to Discord, so a line typed in one place reaches the whole network. The messenger of the gods, doing messenger work." flip />

<Highlight n="05" kicker="Iris · Cross-server sync" title="One identity, every server." body="Iris keeps inventories, stats, and progress in step as players move between servers, so the network feels like one world instead of a row of separate ones. Named for the goddess who links the realms." />

<Outcome title="Why it is built this way.">

Five small mods, each with one responsibility, are easier to run and reason about than one that tries to do everything. The Greek naming is not decoration: each figure's domain maps to the mod's job, so the whole toolset reads as a single system.
