# calamity-matchmaking: media folders

Keep each section’s images and videos together. Adding files does not automatically publish them.

- `hero/`: current cover and trailer.
- `gallery/`: general gallery artwork, not feature-section media.

This page currently has no authored feature sections. No speculative sections have been added.


Section folders are under `sections/`. Case-study media is connected in `content/portfolio/pages.json`; Sidequest content is connected in `content/projects/calamity-matchmaking.mdx`. Shared images can be referenced from another section without copying them.
