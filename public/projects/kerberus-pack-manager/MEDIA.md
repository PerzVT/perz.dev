# kerberus-pack-manager: media folders

Keep each section’s images and videos together. Adding files does not automatically publish them.

- `hero/`: current cover and trailer.
- `gallery/`: general gallery artwork, not feature-section media.

- **Shipping a pack by hand is a dozen careful steps.** — `01-the-problem/` (live)
- **One guided flow, changelog to publish.** — `02-the-release-wizard/` (live)
- **A real desktop tool, not a script.** — `03-under-the-hood/` (live)
- **Debugging that reads the logs for you.** — `04-next/` (live)

Section folders are under `sections/`. Case-study media is connected in `content/portfolio/pages.json`; Sidequest content is connected in `content/projects/kerberus-pack-manager.mdx`. Shared images can be referenced from another section without copying them.
